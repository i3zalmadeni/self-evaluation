# معمارية النظام

## الموقع بين الأنظمة
```
النواة الرقمية (i3zalmadeni/digital-core)  ← المنسوبون، الأعوام، الأدوار، الصلاحيات، سجل الأنظمة
        │  نفس مشروع Supabase (labeedsch_PC) ونفس auth.users
        ▼
التقويم الذاتي الذكي (i3zalmadeni/self-evaluation) ← جداول se_ فقط
```
مستودعان مستقلان (كود ونشر وتاريخ)، وقاعدة بيانات واحدة. المستودع هو ما يُستقل به النظام؛ القاعدة هي ما يربطه بالنواة.

## الطبقات
- **الواجهة** `site/`: HTML وJS ثابتان، RTL، بهوية النواة. `assets/se.js` يحوي الجلسة والصلاحيات والإطار، وكل صفحة ملف `p-*.js`.
- **القاعدة**: جداول `se_` وعروضها ودوالها وسياسات RLS. المنطق الحساس (اشتقاق المستوى من نسبة التحقق، تاريخ الاعتماد، حراسة الشواهد) في قاعدة البيانات لا في الواجهة.
- **الملفات**: حاوية Storage خاصة للشواهد بسياسات على مستوى القاعدة.

## تدفق الدخول
1. `signInWithPassword` ببريد النواة وكلمة مرورها.
2. جلب `staff_members` بـ`user_id`؛ إن لم يوجد سجل يُخرَج المستخدم.
3. استدعاء `is_core_admin` و`se_is_coordinator` و`se_is_team_member` و`core_can('self_evaluation:view')`.
4. إن لم يتحقق أي منها تظهر رسالة «غير مرتبط بالنظام» دون قائمة.

## دورة الدورة (cycle)
كل دورة تثبّت `guide_id` (إصدار الدليل)، فلا تتأثر الدورات السابقة بتحديث الدليل. المؤشرات الخاصة بالمدارس الأهلية مستثناة (49 من 52 للمدرسة الحكومية).
